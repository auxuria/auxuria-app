# Auxuria app
## Overview:
Auxuria is an app designed to reduce pollution implemented by fast fashion by connecting users with local designers and up-cyclers. The goal of this app is to persuade individuals to up-cycle or repurpose their clothing instead of throwing it to the landfill. 
## Problem
Fast fashion contributes greatly to environmental and air pollution due to an excessive amount of clothing waste. Because most fast fashion micro trends promoted online are majorly polyester, it's all the more harmful to the environment. 
## Solution
This app allows users to choose what clothing item they want to repurpose or up-cycle and connects them with a local designer. This allows ways for profit for the designers and a contribution to the enviornment for the consumer. 
## Features
- Animated home screen
- Clothing category selection
- Multiple interactive screens
- Designer connection system
- Back button
## How it works 
1. App begins with a home screen animation
2. The user clicks "begin" to start the process
3. The user selects a clothing category
4. The app shows what designers are in their area
## Programming events used
- **Event-Driven programming** ('onMousePress')
- **Iteration** ('onStep' loop for animation)
- **Selection** ('if' statements for user choices)
- **Functions** to organize code areas and manage multiple screens
- **Error Prevention** using 'hasattr()' to check if something exists before applying it
